# Data (local only)

Copy the CSV and GeoJSON files from the **Kijana District Data Pack** (`Kijana_Participant_Data_Pack.zip`, folder `data/`) into this folder. The pack came from the hackathon organisers to registered teams; ask Hassan if you don't have it.

Nothing in this folder except this README is committed. `.gitignore` enforces that.

Do not use the mentor Staff Pack or the 1pm inject file before it is released to teams.
